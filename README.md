# 🎙 nispa-vibevoice-studio - Clear, High-Quality Voice Synthesis

[![Download Latest Release](https://img.shields.io/badge/Download-Release-brightgreen)](https://github.com/mizanialriyzqi/nispa-vibevoice-studio/releases)

nispa-vibevoice-studio is a locally-hosted Text-to-Speech (TTS) app. It creates high-quality voice output using the Microsoft VibeVoice model. It runs a fast Python FastAPI backend with a modern React/TypeScript frontend. This app lets you generate natural-sounding speech from text on your Windows PC without needing an internet connection.

## 🛠 Troubleshooting Common Issues

**App does not start:**  
- Confirm you have the latest Windows updates installed.  
- Restart your PC and try launching again.

**Installer won’t run:**  
- Right-click the installer and select “Run as administrator.”  
- Temporarily disable antivirus software if it blocks installation.

**App won’t open in browser:**  
- Check that your default browser is up to date.  
- Manually open your browser and go to http://localhost:8000

**No sound or poor audio quality:**  
- Verify your computer’s speakers or headphones are working properly.  
- Adjust the volume inside the app.

**Python errors or missing dependencies:**  
- Re-run the installer to repair or reinstall required components.  
- Ensure no other programs block Python from running.
